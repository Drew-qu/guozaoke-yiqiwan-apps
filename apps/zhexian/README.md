# 折线 · 一起玩

三种玩法共用一套壳：

| 玩法 | 规则 | 难在哪 |
|------|------|--------|
| **折线** | 任意角度连点，不交叉；可有墙 / S·E | 房间顺序、窄口、堵死 |
| **描边** | 沿预置灰边走完每条边（点可重复） | 欧拉路径 / 奇点起终点 |
| **填格** | 网格上下左右相邻，一笔填满 | 死角与奇偶性 |

生涯 / 每日 / 三难度 / 拖拽 / 五声音效 / 过关显形 / 分玩法排行榜。
